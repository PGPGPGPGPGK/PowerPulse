Data & Browser Storage Notice

Effective date: 18 September 2026

1. No advertising or marketing cookies

PowerPulse does not currently use advertising cookies, marketing cookies, behavioural advertising trackers, or advertising analytics. Because PowerPulse does not currently use optional advertising or marketing cookies, it does not display a generic "accept all cookies" banner.

2. Browser storage used for essential functionality

PowerPulse and Firebase may use browser storage necessary for application functionality, including to:

  • maintain an anonymous Firebase authentication session;
  • remember local application state or preferences;
  • remember whether the 18+ legal acknowledgement has been accepted for the current legal version; and
  • support normal security and application operation.

This storage is functional rather than advertising-related.

3. Anonymous Firebase session

PowerPulse uses Firebase Anonymous Authentication. The anonymous session allows PowerPulse to distinguish repeated observations from the same anonymous account from reports submitted by other anonymous users. If you clear browser/site data, use a different browser profile, or use another device, PowerPulse may no longer recognise you as the same anonymous user.

4. Location data

When you choose to use device location, PowerPulse may hold your current device position in browser memory for local functionality. The precise device coordinate is not intentionally persisted as a community report. Before an outage report is stored, the location is deliberately coarsened to an approximately 100-metre grid.

5. Interactive map requests

The interactive map loads map resources from OpenFreeMap and OpenStreetMap-derived data sources. Loading those resources creates network requests to the map provider and its infrastructure. PowerPulse does not send community report records or reporter identities to the map provider.

6. Analytics

PowerPulse currently does not use non-essential behavioural analytics or advertising tracking. If optional analytics, advertising technologies, or similar tracking tools are introduced later, this notice and any legally required consent controls will be updated before those tools are enabled.

7. Managing browser storage

You can remove PowerPulse site data through your browser's privacy or site-data settings. Removing site data may reset your anonymous Firebase session, local settings, and legal acknowledgement, and may prevent PowerPulse from recognising previous reports as belonging to the same anonymous account.
